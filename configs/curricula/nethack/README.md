# NetHack curricula

`score.json` plays base NetHack (`NetHackScore-v0`), distinct from the `minihack` backend's tasks: the terminal's TTY grid is rendered to pixels; arrow keys move (vi-keys N/E/S/W) and SPACE sends ENTER, which confirms prompts.

**Setup.** `uv sync --extra nethack` (nle, which needs setuptools<81).
