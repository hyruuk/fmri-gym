# Demos

- `mixed.json`: several backends in one run. VGDL (Aliens) needs the `external/vgdl` checkout (README, "External checkouts"); Box2D (CarRacing) needs the `box2d` extra; Crafter and MiniHack their extras; AI GameStore (Water Sort) playwright and a system Chrome.
- `meg.json`: a template for a rig whose recording starts from the trigger line, a curriculum plus a `triggers` section. `sync.mode` `send` emits `scanner_start` on the trigger line after the experimenter's SPACE (MEG acquisitions started from the trigger input); `wait` is for an fMRI trigger box. `backend` is null, lsl, serial or parallel (the `triggers` extra); a backend that cannot be opened stops the run with the reason. Codes are non-overlapping bit fields (frames 1-7, lifecycle bits 8/16/32/64); see README, "Triggers". Game sound plays through the system's default output, a constant delay after each frame's flip (printed at start-up, logged); measure the rig's real audio offset with `python -m fmri_gym.photodiode --audio-click`.
